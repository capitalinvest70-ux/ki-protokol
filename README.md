# Протоколи КИ

Приложение за телефон (Android) и компютър (Windows), което отваря **Програма за протокол**
(https://protocol-app-production-cc1d.up.railway.app/) с вида на Капитал Инвест: тъмносиньо,
големи букви и бърз панел:

- ➕ Ново събрание – един екран, всичко попълнено
- ✍️ Готови текстове – от последното приключило събрание от същия вид
- ✅ Всички присъстващи ЗА
- 📄 Всички документи – протокол, договор, уведомление до общината

Данните остават в Програма за протокол – няма нов сървър и нова база.

## Сваляне
GitHub → **Releases** → последната версия:
- `Protokoli-KI-v…apk` – за телефона
- `Protokoli-KI-Setup-v….exe` – за компютъра

## Промени
`skin.js` – вида и бутоните (общ за двете). `desktop/` – Windows. `mobile/` – Android.
Всяко качване в GitHub строи нова версия автоматично.
